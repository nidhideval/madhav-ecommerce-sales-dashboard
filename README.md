# Madhav Ecommerce Sales Dashboard

## Project Overview
A beginner-level e-commerce sales analysis project created using Microsoft Power BI while following a YouTube tutorial.

## Tools Used
- Microsoft Power BI
- Power Query
- Data visualization
- DAX and data modelling concepts covered in the tutorial

## Key Performance Indicators
- Total Sales: 438K
- Total Profit: 37K
- Total Quantity: 6K
- AOV displayed: 121K

## Business Insights
1. Maharashtra records the highest sales among the four states displayed.
2. Clothing accounts for approximately 63% of the quantity sold.
3. November shows the highest positive monthly profit, while several months show negative profit.
4. Printers appear to generate the highest profit among the displayed sub-categories.
5. COD accounts for 44% of quantity by payment mode, making it the largest payment-mode segment shown.
